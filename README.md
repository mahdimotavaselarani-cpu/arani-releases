# ARANI — Android app releases

Public distribution point for **signed ARANI Android APK updates**.

- Only versioned release assets named `ARANI-vX.Y.Z.apk` and the matching `ARANI-vX.Y.Z.apk.sha256` are published here.
- Application source, customer data, credentials, signing keys, and Google Sheets contents are **not** published in this repository.
- The installed ARANI app verifies downloaded APK files against their SHA-256 hashes before asking the user to approve installation.
- Android still requires user confirmation to install an update.
